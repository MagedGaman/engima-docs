The browser profile is the persistent Chrome data — cookies, local storage, extensions — stored inside an environment. This page documents the API endpoints for creating environments, managing their profile data, and using them in sessions.

## Authentication

All endpoints require an API key with `task:create` permission.

```bash
Authorization: Bearer <api_key>
```

## Base URL

```
https://connect.webrun.ai
```

---

## Create Environment

Creates a new environment with an empty browser profile.

```
POST /environments
Content-Type: application/json
```

### Request Body

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `name` | string | Yes | Environment name (max 100 characters) |
| `description` | string | No | Description (max 500 characters) |

**Example:**

```bash
curl -X POST https://connect.webrun.ai/environments \
  -H "Authorization: Bearer enig_iMM4HaeRczq0sGnyXB8JxhvnYli2pRu6" \
  -H "Content-Type: application/json" \
  -d '{"name": "my-environment", "description": "For social media automation"}'
```

**Response:**

```json
{
  "success": true,
  "message": "Environment created",
  "environment": {
    "_id": "683a1f2e4b0c1d2e3f4a5b6c",
    "userId": "67f1a2b3c4d5e6f7a8b9c0d1",
    "name": "my-environment",
    "description": "For social media automation",
    "status": "empty",
    "usageCount": 0,
    "createdAt": "2026-02-09T12:00:00.000Z",
    "updatedAt": "2026-02-09T12:00:00.000Z"
  }
}
```

### Errors

| Status | Message | Cause |
|--------|---------|-------|
| 400 | Name is required | Missing or empty `name` field |
| 400 | Maximum of 20 environments allowed | User already has 20 environments |

## List Environments

Returns all environments for the authenticated user, sorted by newest first.

```
GET /environments
```

**Example:**

```bash
curl https://connect.webrun.ai/environments \
  -H "Authorization: Bearer enig_iMM4HaeRczq0sGnyXB8JxhvnYli2pRu6"
```

**Response:**

```json
{
  "success": true,
  "environments": [
    {
      "_id": "683a1f2e4b0c1d2e3f4a5b6c",
      "userId": "67f1a2b3c4d5e6f7a8b9c0d1",
      "name": "my-environment",
      "description": "For social media automation",
      "blobSize": 4521984,
      "blobUploadedAt": "2026-02-08T14:30:00.000Z",
      "lastUsedAt": "2026-02-09T10:15:00.000Z",
      "usageCount": 12,
      "status": "ready",
      "createdAt": "2026-02-01T09:00:00.000Z",
      "updatedAt": "2026-02-09T10:15:00.000Z"
    }
  ]
}
```

### Response Fields

| Field | Type | Description |
|-------|------|-------------|
| `_id` | string | Unique environment identifier |
| `userId` | string | Owner's user ID |
| `name` | string | Environment name |
| `description` | string | Environment description |
| `blobSize` | number | Size of profile data in bytes |
| `blobUploadedAt` | string | ISO 8601 timestamp of last profile upload |
| `lastUsedAt` | string | ISO 8601 timestamp of last session usage |
| `usageCount` | number | Number of times used in sessions |
| `status` | string | Profile status: `empty`, `uploading`, or `ready` |
| `createdAt` | string | ISO 8601 creation timestamp |
| `updatedAt` | string | ISO 8601 last update timestamp |

## Delete Environment

Permanently deletes an environment, its browser profile data, and all attached files.

```
DELETE /environments/<ENV_ID>
```

**Example:**

```bash
curl -X DELETE https://connect.webrun.ai/environments/683a1f2e4b0c1d2e3f4a5b6c \
  -H "Authorization: Bearer enig_iMM4HaeRczq0sGnyXB8JxhvnYli2pRu6"
```

**Response:**

```json
{
  "success": true,
  "message": "Environment deleted"
}
```

### Errors

| Status | Message | Cause |
|--------|---------|-------|
| 404 | Environment not found | Invalid ID or environment belongs to another user |

## Upload Browser Profile Data

Uploads a `.tar.gz` Chrome browser profile archive to an environment. Replaces any existing profile data. Sets the environment status to `ready` on success.

```
POST /environments/<ENV_ID>/upload
Content-Type: multipart/form-data
```

### Parameters

| Parameter | Location | Description |
|-----------|----------|-------------|
| `ENV_ID` | URL path | The environment ID |
| `file` | Form field | The `.tar.gz` browser profile archive (max 500 MB) |

**Example:**

```bash
curl -X POST https://connect.webrun.ai/environments/683a1f2e4b0c1d2e3f4a5b6c/upload \
  -H "Authorization: Bearer enig_iMM4HaeRczq0sGnyXB8JxhvnYli2pRu6" \
  -F "file=@my-profile.tar.gz"
```

**Response:**

```json
{
  "success": true,
  "message": "Profile uploaded successfully",
  "environment": {
    "_id": "683a1f2e4b0c1d2e3f4a5b6c",
    "name": "my-environment",
    "status": "ready",
    "blobSize": 4521984,
    "blobUploadedAt": "2026-02-09T12:30:00.000Z"
  }
}
```

**Accepted file types:** `.tar.gz`, `.tgz`

### Errors

| Status | Message | Cause |
|--------|---------|-------|
| 400 | No file provided | Missing `file` field in form data |
| 400 | Only .tar.gz files are allowed | File is not a valid tar.gz archive |
| 404 | Environment not found | Invalid ID or environment belongs to another user |

<Tip>
To sync a local Chrome profile instead of uploading a manual archive, use the [Sync Profiles](/environments/sync-profiles) tool.
</Tip>

## Download Profile Data

Returns a temporary signed URL to download the environment's browser profile as a `.tar.gz` archive. The URL expires after 1 hour.

```
GET /profiles/<ENV_ID>/download
```

### Parameters

| Parameter | Location | Description |
|-----------|----------|-------------|
| `ENV_ID` | URL path | The environment ID |

**Example:**

```bash
curl https://connect.webrun.ai/profiles/683a1f2e4b0c1d2e3f4a5b6c/download \
  -H "Authorization: Bearer enig_iMM4HaeRczq0sGnyXB8JxhvnYli2pRu6"
```

**Response:**

```json
{
  "success": true,
  "downloadUrl": "https://storage.example.com/profiles/683a1f2e4b0c1d2e3f4a5b6c.tar.gz?token=eyJhbGciOi..."
}
```

Use the `downloadUrl` to download the file:

```bash
curl -o profile-backup.tar.gz "<downloadUrl>"
```

### Errors

| Status | Message | Cause |
|--------|---------|-------|
| 400 | Profile has no data to download | Environment status is not `ready` |
| 404 | Profile not found | Invalid ID or environment belongs to another user |

---

## Profile Status Values

| Status | Description |
|--------|-------------|
| `empty` | Created but has no browser data yet |
| `uploading` | Data upload in progress |
| `ready` | Has browser data and can be used in sessions |

## Using an Environment in a Session

Pass `environmentId` as a top-level parameter when starting a session or running a task:

```bash
curl -X POST https://connect.webrun.ai/start/run-task \
  -H "Authorization: Bearer enig_iMM4HaeRczq0sGnyXB8JxhvnYli2pRu6" \
  -H "Content-Type: application/json" \
  -d '{
    "taskDetails": "Check my order status",
    "environmentId": "683a1f2e4b0c1d2e3f4a5b6c"
  }'
```

---

## Rate Limits

Environment endpoints share the server's global rate limit of **100 requests per 15 minutes per IP**.

---

## Common Error Responses

```json
{
  "success": false,
  "message": "Description of the error"
}
```

| Status | Message | Cause |
|--------|---------|-------|
| 401 | API key required | Missing Authorization header |
| 401 | Invalid or revoked API key | API key is incorrect or has been revoked |
| 403 | Account is deactivated | User account is disabled |
| 403 | API key missing required permission: task:create | API key lacks the `task:create` permission |
| 500 | Authentication error | Server-side authentication failure |
