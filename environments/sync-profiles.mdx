Use the sync command to upload your local Chrome browser profile — cookies, local storage, extensions, and saved state — directly to an environment. This is the fastest way to get an environment's browser profile ready for use in sessions.

---

## Sync to an Existing Environment

If you've already [created an environment](/environments/environments-api#create-environment), sync your local browser data to it:

```bash
bash <(curl -fsSL https://webrun.ai/sync/sync.sh) --environmentId <environmentId> --key <apiKey>
```

| Parameter | Description |
|-----------|-------------|
| `--environmentId` | The ID of the existing environment to sync to |
| `--key` | Your WebRun API key |

This uploads your local Chrome profile data to the specified environment, replacing any existing profile data. The environment status changes to `ready` once the upload completes.

---

## Create and Upload in One Step

To create a new environment and upload your local data in a single command, omit the `--environmentId` flag:

```bash
bash <(curl -fsSL https://webrun.ai/sync/sync.sh) --key <apiKey>
```

This will:

1. Create a new environment on your account
2. Upload your local Chrome profile data to it
3. Return the new environment ID for use in sessions

<Tip>
Save the environment ID returned by the command — you'll need it to attach the environment to sessions via `environmentId`.
</Tip>

---

## When to Use Sync

| Scenario | Approach |
|----------|----------|
| You're already logged into sites locally and want to reuse that state | **Sync** your local profile |
| You want to set up an environment from scratch via automation | Use the [API](/environments/environments-api#create-environment) to create an environment, then run a session to populate it |
| You need to back up or transfer a profile | Use the [download endpoint](/environments/profile-management-api#download-profile-data) |
