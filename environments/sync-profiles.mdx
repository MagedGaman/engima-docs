The sync command packages your local Chrome browser data — cookies, local storage, extensions, saved state — and uploads it directly to an environment. This is the fastest way to populate an environment's browser profile.

---

## Sync to an Existing Environment

If you've already [created an environment](/environments/environments-api#create-an-environment), sync your local browser data to it:

```bash
bash <(curl -fsSL https://webrun.ai/sync/sync.sh) --environmentId <environmentId> --key <apiKey>
```

| Parameter | Description |
|-----------|-------------|
| `--environmentId` | The ID of the environment to sync to |
| `--key` | Your WebRun API key |

This uploads your local Chrome profile to the specified environment, replacing any existing profile data. The environment status changes to `ready` once the upload completes.

---

## Create and Sync in One Step

To create a new environment and upload your local data in a single command, omit `--environmentId`:

```bash
bash <(curl -fsSL https://webrun.ai/sync/sync.sh) --key <apiKey>
```

This creates a new environment on your account, uploads your Chrome profile, and returns the new environment ID.

<Tip>
Save the environment ID returned by the command — you'll need it to pass as `environmentId` when starting sessions.
</Tip>

---

## When to Use Sync

| Scenario | Approach |
|----------|----------|
| You're already logged into sites locally and want to reuse that state | **Sync** your local profile |
| You want to set up an environment from scratch via automation | Use the [Environments API](/environments/environments-api#create-an-environment) to create one, then run a session to populate it |
| You need to back up or transfer a profile | Use the [download endpoint](/environments/profile-management-api#download-profile-data) |
